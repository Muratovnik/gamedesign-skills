# Быстрый старт

Это самостоятельный исходный пакет Game Design версии 0.1.1. Он помогает
создавать и изменять конкретные правила, действия, миры, сцены, системы ресурсов,
условия участия и наборы содержания. Семь навыков можно вызывать напрямую;
установка одной директории без остальных не поддерживается.

Откройте исходный код из разрешённой рабочей директории. Передайте агенту
абсолютные пути к Game Design и игре. Если операция требует общих методов,
предоставьте отдельно поддерживаемый Assay по его собственным правилам.
Текущий binding требует Assay 0.17.2, commit
`94c517b0aac9ba2575086bf9aead1cc828aadb0d`.
Укажите текущий артефакт, желаемое изменение и границы разрешённых действий. Для узкой задачи достаточно
соответствующего `SKILL.md` и относящихся references.

Из корня Game Design выполните проверку и чтение нужного метода Assay:

```bash
python3 skills/game-design/scripts/bind_assay.py --assay-root /absolute/assay --provider-state enabled --method evidence-research --read
```

Подставьте фактический путь. Нельзя объявлять отключённый источник включённым,
чтобы пройти проверку: параметр сообщает состояние выбранного маршрута и не
доказывает разрешение клиента. При изменении нужных файлов проверка остановит
зависимую операцию, сохранив остальную работу.

Для первого запуска без движка попробуйте [East Gate](../examples/adaptation/README.md):
JSON с русской загадкой проходит через выбор строк, выбор направления и выдачу
следующей сцены. [Godot](../examples/godot-episode/README.md) проверяет реальный
ввод и физику; [analysis lab](../examples/analysis-lab/README.md) — ресурсы,
сохранения, разные стороны, содержание и игровые данные. Бумажные разыгрываемые
примеры собраны в [путеводителе](examples.md).

Для установки через Codex или Claude Code пакет содержит каталоги плагинов с идентификатором
`game-design@game-design-source`. В [инструкции по установке](installation.md)
даны команды, область действия, проверка конфликтов, отключение,
удаление, обновление и возврат к сохранённой версии. Команды встроенного менеджера
выполняет владелец установки; для Claude выбран `local` в репозитории игры.
Для Codex регистрация и кеш принадлежат клиенту, а включение можно задать
в конфигурации доверенного проекта.

Работа этих маршрутов в конкретных сборках клиентов ещё требует подтверждения
сохранёнными результатами запуска. Проверка manifests не подтверждает обнаружение
или фактическую загрузку навыков. Модельная оценка,
пользовательский плейтест и квалификация для произвольных движков не заявлены.
Headless-сценарий не является наблюдением восприятия или человеческим
плейтестом. Подробнее — [границы совместимости](compatibility.md).

Для подготовки архива используйте [инструкцию по выпуску](releases.md).
Подготовка архива сама по себе не публикует репозиторий и не меняет настройки
клиента.
