# Быстрый старт

Game Design — исходный пакет из семи связанных методов для создания и изменения
игр. Выберите подходящий `skills/<name>/SKILL.md` и передайте его содержимое
разрешённому текстовому читателю вместе с текущим артефактом игры, целью работы
и границами разрешённых действий. Укажите абсолютные пути к каталогу пакета и
корню игры. Для узкой задачи начните с одного метода и его относящихся ссылок;
устанавливать все семь методов в клиент не требуется, чтобы прочитать их из
исходников.

## Первый результат

Включённая игра [East Gate](../examples/adaptation/README.md) показывает
адаптацию загадки на русском языке. Из корня распакованного каталога
`game-design/` выполните в Bash команду ниже. Нужен Python 3.11 или новее и новый
путь для выходного файла:

```bash
mkdir -p tmp
python3 examples/adaptation/consumer.py \
  --artifact examples/adaptation/fixtures/east-gate-ru.json \
  --expect-revision east-gate-ru-2 \
  --pin 1 --pin 2 --pin 3 --pin 4 --pin 5 --pin 6 \
  --choose east \
  --output tmp/east-gate-result.json
```

Инструкции для Windows PowerShell приведены в [руководстве по East Gate](../examples/adaptation/README.md#run-the-example).

Успешный ответ CLI содержит `status: executed` и `gate: open`. В JSON-файле
будут записи закреплённых строк, жетон перевозчика и следующая сцена. Если файл
с таким именем уже существует, выберите другое имя: потребитель создаёт новый
файл и отказывает при занятом пути. Это ожидаемая форма результата по исходному
коду примера, а не запись о запуске на вашем устройстве. В руководстве East Gate
показаны также допустимый неверный выбор и отказ на повреждённом содержимом.

## Assay для задач, которым он нужен

Общие методы исследования и инженерии поддерживаются отдельно в Assay.
Текущая привязка Game Design требует исходник Assay 0.17.2 с commit
`94c517b0aac9ba2575086bf9aead1cc828aadb0d`; пакет не устанавливает его. Если
задаче нужен такой метод, из корня Game Design можно проверить разрешённый
исходный каталог и прочитать выбранный метод:

```bash
python3 skills/game-design/scripts/bind_assay.py \
  --assay-root /absolute/assay \
  --provider-state enabled \
  --method evidence-research \
  --read
```

Замените `/absolute/assay` фактическим путём к выбранному исходнику. Параметр
`--provider-state enabled` сообщает состояние выбранного маршрута со стороны
вызывающего кода; сам по себе он не подтверждает разрешение клиента. Не
используйте этот обход для чтения отключённого клиентского источника. Подробные
условия проверки и смысл ответов описаны в
[контракте потребителя и Assay](../skills/game-design/references/consumer-and-assay-contract.md).

## Установка в клиенте — необязательный маршрут

При необходимости можно зарегистрировать тот же полный пакет в Codex или Claude
Code. Это отдельное действие владельца установки; команды, область действия,
конфликты и удаление собраны в [руководстве по установке](installation.md).
Наличие manifest-файлов и чтение исходника не подтверждают автоматическое
обнаружение или успешный жизненный цикл плагина. Квалификация native-маршрутов
обоих клиентов остаётся непроверенной; точные границы приведены в
[документе о совместимости](compatibility.md#native-client-qualification).

Для примеров на движке, анализа игровых данных и бумажных разыгрываемых историй
см. [путеводитель по примерам](examples.md). Исходники и иллюстративные
результаты не являются пользовательским плейтестом.
