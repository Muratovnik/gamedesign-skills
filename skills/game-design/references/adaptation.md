# Adapt a game relation

Use when language, input, display, device or physical material changes what a
participant can notice, infer, remember, do or express. A spelling repair
that changes none of these can remain a technical/local edit.

## Preserve a function deliberately

Recover the source and target in their actual context, including variable names,
grammatical substitutions, choice IDs, icons, spatial layout, control and later
references. Describe the relation to retain before deciding which bytes survive:

`feature → available distinction → player's operation → action → state → later reference`

Choose a target construction. Literal transfer, a new gesture, a rearranged
workspace, an external note and replacement of the puzzle itself can all be
valid. State the price paid in the valued relation. A newly helpful journal can
preserve comparison or take over deduction; those are different adaptations.

For altered clue reasoning read [inference](../../game-information-design/references/inference.md);
for cognitive help read [learning and help](../../game-information-design/references/learning-and-help.md);
for access read [participation](../../game-participation-design/references/access-and-return.md).
Use the state-transfer owner when IDs/conditions/saves change.

## Worked target: the East Gate verse

Original synthetic paper puzzle. Purpose: notice a repeated formal feature and
express a direction. The source gate accepts direction ID `east`, not the exact
English answer string. Players may point to a direction; hearing a reading does
not have to be the only channel.

English wall, shown as four separate lines:

> Evening ferries sleep.
> Ash settles on the rope.
> Salt marks the stones.
> Tide returns the key.

A carved guide says, "The beginning of each watch points the way." The four
initial letters yield EAST. The direction panel has north/east/south/west.

A literal Russian translation does not retain those initials. The target is a
new six-line wall, with the same formal operation and direction ID:

> Вечер прячет лодки.
> Отмель держит след.
> Соль белеет на канате.
> Тихо гаснет маяк.
> Огонь хранит смотритель.
> Ключ уносит прилив.

The guide becomes «Начало каждой вахты указывает путь». Initials yield ВОСТОК.
The word count, images and reading rhythm change; the operation and outcome are
preserved. A later sign says «Восточные ворота открыты», keyed to the same state.
No inference about cultural reception follows from this structural construction.

On a narrow display, a single-line carousel makes comparison depend on memory.
Offer a player-controlled pinboard that holds selected *whole lines*, retaining
line boundaries; do not automatically extract initials and open the gate. A
permanent reading aid can remain. If the target's purpose is narrative access,
an explicit answer is also permissible, but then deduction is intentionally removed.

## Reenact the dependent path

Inspect the target presentation, gather the available initials, express `east`,
change the gate state and read the later sign. Repeat with line order changed,
variable text inserted or assistance active where supported. A schema-valid
string table can still reveal a hidden gender, destroy wordplay or hide a needed
document. An allowed early answer need not require a flag for every read line.

Review the changed fragment together with its consumers. Keep a versioned pair
of source/target artifacts and identify unexecuted device/perceptual claims.
Structural checking can finish a specification; implemented presentation and
human language/interaction claims require their own material. Do not substitute
another demo for a promised change to an existing game.

## Evidence and limits

This transfer is a design judgment, not a tested equivalence formula.
[Lucas Pope's mobile devlog](https://dukope.com/devlogs/papers-please/mobile/)
documents changing a workspace and retaining a way to pin information for
comparison. [His localization account](https://dukope.com/devlogs/papers-please/localizing-2/)
documents changes to style, names and grammatical composition. Both are author
accounts of one game; neither establishes identical interpretation across
audiences. The verse and pinboard above are original design alternatives.
